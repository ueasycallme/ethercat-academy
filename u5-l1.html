CiA402 状态机与控制字、状态字

驱动器里有第二台状态机：主站只能写 6040 控制字、读 6041 状态字，一步一步把电机从断电带到运行使能。

定位

本课目标

  1. 画出 CiA402 的 8 个状态和 0–16 号转换。
  2. 用掩码 0x004F / 0x006F 从 6041 判定状态，用 6040 发出正确的命令。
  3. 解释 6041 bit4 Voltage enabled 与 bit9 Remote 的含义。

    机制拆解

    八个状态：怎么从 6041 认出来

    6041 的 bit0–3、bit5、bit6 共同编码当前状态，其余位（电压、警告、远程、模式相关、厂商位）会随工况变化，所以必须先与掩码再比较。表里 x 表示不关心的位；bit5 Quick stop 是低有效，0 才表示正在快停。

    状态6041 位型（bit7…0）掩码掩码后等于功率级 / 电机
    Not ready to switch on 未就绪x0xx 00000x004F0x0000自检中，不出力
    Switch on disabled 禁止接通x1xx 00000x004F0x0040不出力；母线可能已带电（看 bit4）
    Ready to switch on 准备接通x01x 00010x006F0x0021不出力
    Switched on 已接通x01x 00110x006F0x0023功率级就绪但驱动功能未使能
    Operation enabled 运行使能x01x 01110x006F0x0027出力，电机受控
    Quick stop active 快速停止x00x 01110x006F0x0007出力，按 605A 停车
    Fault reaction active 故障反应x0xx 11110x004F0x000F按 605E 执行故障反应

    另外两位常被问到：bit4 Voltage enabled = 1 表示高压（直流母线）已加到驱动器，它不参与状态判定；bit9 Remote = 1 表示控制字正在被执行，为 0 时驱动器处于本地控制（例如被调试软件接管），主站写 6040 不起作用。bit7 Warning 是警告不是故障，bit8、bit14、bit15 为厂商定义，bit10–13 的含义随运行模式变化（见 u5-l2）。

    十七个转换编号

    转换 0、1、13、14 由驱动器自己触发，12 在停车完成后也可自动发生，其余都由主站写 6040 触发。同一条命令在不同状态下对应不同转换，例如 Shutdown 可以是 2、6 或 8。

    控制字 6040：五个位组成的命令

    6040 的 bit0 Switch on、bit1 Enable voltage、bit2 Quick stop（低有效）、bit3 Enable operation、bit7 Fault reset 组合成命令；bit4–6、bit9 随模式定义，bit8 为 Halt，bit11–15 为厂商定义。x 表示该命令不看这一位，所以 Disable voltage 只要 bit1 = 0 就成立。

    主从对照

    主站做什么

    • 每个周期在 RxPDO 里写 6040，在 TxPDO 里读 6041。
    • 先用掩码判定当前状态，再按状态选下一条命令，一次只走一步：0x0006 → 0x0007 → 0x000F。
    • 复位故障时先让 bit7 = 0 至少一个周期，再写 1，制造上升沿。
    • 把"总线在 OP"当成前提而不是结果：ESM 到 OP 之后，CiA402 状态机仍停在禁止接通。

    从站做什么

    • 每个控制周期读 6040，按当前状态查转换表，只执行合法转换，不合法的命令被忽略。
    • 自己触发转换 0、1、13、14，快停完成后按 605A 自动走 12。
    • 把状态编码进 6041 bit0–3、5、6，同时刷新 bit4 电压、bit7 警告、bit9 远程。
    • 执行停车选项码 605A、605B、605C、605E 规定的停车方式（u5-l3）。

    在真机上看

    主站程序不运行时，可以用 IgH 命令行通过 SDO 读写。先确认总线状态，再读状态字：

    ethercat slaves                                  # 总线 ESM 状态，例如 OP 或 PREOP
ethercat upload -p0 0x6041 0 --type uint16       # 驱动器 CiA402 状态字

    如果驱动器允许用 SDO 写控制字（是否允许、在哪个 ESM 状态允许因厂商而异；6040 已映射进 PDO 且主站程序在跑时，SDO 写入会被每周期的 PDO 覆盖），可以手动走一遍：

    ethercat download -p0 0x6040 0 0x0006 --type uint16
ethercat upload   -p0 0x6041 0 --type uint16
ethercat download -p0 0x6040 0 0x0007 --type uint16
ethercat upload   -p0 0x6041 0 --type uint16

    主站程序里建议每周期打印状态变化，判定函数只看掩码：

    static const char *cia402_state(uint16_t sw)
{
    if ((sw & 0x004F) == 0x0000) return "Not ready to switch on";
    if ((sw & 0x004F) == 0x0040) return "Switch on disabled";
    if ((sw & 0x006F) == 0x0021) return "Ready to switch on";
    if ((sw & 0x006F) == 0x0023) return "Switched on";
    if ((sw & 0x006F) == 0x0027) return "Operation enabled";
    if ((sw & 0x006F) == 0x0007) return "Quick stop active";
    if ((sw & 0x004F) == 0x000F) return "Fault reaction active";
    if ((sw & 0x004F) == 0x0008) return "Fault";
    return "unknown";
}
    读数期望值（典型）说明
    ethercat slavesOP总线已到 OP，但下一行 6041 仍可能是禁止接通：两台状态机互相独立
    6041 上电后0x0250 或 0x0240禁止接通；bit4 取决于母线是否有电
    6041 写 0x0006 后0x0231准备接通
    6041 写 0x0007 后0x0233已接通
    6041 写 0x000F 后0x0237运行使能；bit10–13 会随模式置位（如 0x1637），只看掩码结果
    6041 故障时0x0218 或 0x0238故障；bit5 在故障状态不参与判定

    高位（bit8、bit14、bit15 厂商位，bit10–13 模式相关位）因厂商和模式而异，表中只保证低 7 位的判定结论。

    自测

    误区与关联

    • 误区：用 sw == 0x0237 判断是否已使能。
      实际上：bit7 警告、bit9 远程、bit10–13 模式位、厂商位都会变，必须 (sw & 0x006F) == 0x0027。
    • 误区：想省事直接从禁止接通写 0x000F。
      实际上：标准状态机只允许逐级转换，禁止接通必须先收到 Shutdown，否则原地不动；主站程序要每周期看 6041 再决定下一条命令。
    • 误区：ethercat slaves 显示 OP，电机就该能动了。
      实际上：OP 只说明 ESM 允许输出过程数据，CiA402 状态机还得靠 6040 一步步走到运行使能。

    关联：ESM 状态机见 u3-l1；6040/6041 在 PDO 里的位置见 u3-l3；停车选项码和故障复位细节在 u5-l3。
