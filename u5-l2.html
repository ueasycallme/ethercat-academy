运行模式：PP/PV/TQ/HM/CSP/CSV/CST

同一个"转到 90°"，换一个 6060 取值，轨迹规划和各级闭环就在主站和驱动器之间换一次位置。

定位

本课目标

  1. 列出常用运行模式及其 6060 取值，会读 6502 支持模式位图。
  2. 说出每种模式下主站给什么对象、驱动器闭哪几个环。
  3. 解释 CSP 下为什么轨迹插补由主站负责，以及每周期的点为什么必须可达。

    模式编号：6060 请求、6061 生效、6502 能力

    主站写 6060 Modes of operation 请求一种模式，驱动器切换完成后在 6061 Modes of operation display 里回显，只有 6061 才代表当前真正生效的模式。6502 Supported drive modes 是 32 位位图，告诉主站这台驱动器支持哪些模式；6060 的负值留给厂商自定义模式。

    谁闭哪个环

    模式的本质是在"轨迹生成 → 位置环 → 速度环 → 转矩环"这条链上划一条分界线：线左边归主站，线右边归驱动器。Profile 类模式（PP/PV/TQ）和 HM 把整条链都交给驱动器，周期同步类模式（CSP/CSV/CST）把分界线逐级往右推。

    CSP 为什么要主站插补

    CSP 下驱动器不再规划轨迹，它把每个周期收到的 607A 当成"下一个周期末应该到的位置"，在两点之间细分后交给位置环。所以轨迹的平滑性、速度和加速度约束全部由主站负责：相邻两点的差除以周期就是隐含速度，一步给太远，驱动器会产生速度尖峰或报跟随误差。插补周期写在 60C2（数值 × 10 的指数次方秒），应与主站周期一致。

    模式相关的控制位和状态位

    6040 的 bit4–6、bit8 和 6041 的 bit10、bit12–13 在不同模式下含义不同，读 6041 之前先看 6061。PP 模式用 bit4 New set-point 与 bit12 Set-point acknowledge 做握手：主站写好 607A 后把 bit4 从 0 置 1，驱动器接收后置 bit12，主站再清 bit4。

    主从对照

    主站做什么

    • PREOP 用 SDO 或 OP 用 PDO 写 6060，等 6061 回显相同值后再按新模式发目标。
    • CSP/CSV/CST：每周期算一个新目标（插补），保证相邻两点在速度、加速度上可达。
    • CSV/CST：用 6064、606C 反馈自己闭外环。
    • PP/HM：写好参数，用 6040 bit4 上升沿启动，看 6041 bit12、bit10 完成握手。
    • 切到 CSP 前把 607A 设成当前 6064，避免使能瞬间跳位。

    从站做什么

    • 读 6060，在允许时切换内部控制结构，并把生效模式写到 6061。
    • 按模式把 607A、60FF 或 6071 接到对应的环入口。
    • CSP 下在两个总线周期之间细分插补，细分周期因厂商而异。
    • 通过 6041 bit10、bit12、bit13 报告到位、应答、跟随误差等模式相关状态。

    在真机上看

    主站程序不运行时用 SDO 查看和切换模式。若 6060 已映射进 RxPDO，主站程序运行时 SDO 写入会被 PDO 覆盖，应在程序里改 PDO 变量。

    ethercat upload   -p0 0x6502 0 --type uint32   # 支持哪些模式
ethercat upload   -p0 0x6061 0 --type int8     # 当前生效模式
ethercat download -p0 0x6060 0 8 --type int8   # 请求 CSP
ethercat upload   -p0 0x6061 0 --type int8     # 应读回 8
ethercat upload   -p0 0x60C2 1 --type uint8    # 插补周期数值
ethercat upload   -p0 0x60C2 2 --type int8     # 插补周期指数
ethercat upload   -p0 0x6064 0 --type int32    # 实际位置
ethercat pdos -p0                              # 看 6060/607A/60FF/6071 是否已映射
    读数期望值（示例）说明
    65020x000003ADbit0、2、3、5、7、8、9 为 1：支持 PP、PV、TQ、HM、CSP、CSV、CST；实际位图因产品而异
    6061（写 6060 = 8 后）8切换已生效；若仍是旧值，说明驱动器在当前状态不允许切换或未完成
    60C2:01 / 60C2:021 / -31 × 10-3 s = 1 ms，应等于主站周期；部分驱动器改从 1C32 取周期，因厂商而异
    6064随电机转动变化单位为编码器 counts（或经 6091/6092 换算的用户单位），切 CSP 前拷给 607A

    自测

    误区与关联

    • 误区：切到 CSP 并使能时 607A 还是 0 或上次的旧值。
      实际上：驱动器会立刻把 607A 当成目标，电机猛冲到那里甚至报跟随误差；使能前先让 607A = 6064。
    • 误区：读 6060 判断当前模式。
      实际上：6060 是请求，6061 才是生效模式，模式相关位（6041 bit10、bit12、bit13）也要按 6061 解释。
    • 误区：PP 模式下反复改 607A 电机就会跟着动。
      实际上：PP 需要 6040 bit4 New set-point 上升沿触发，并等 6041 bit12 应答，否则新目标不会被接收。

    关联：状态机和控制字见 u5-l1；停车与故障时模式如何影响停车方式见 u5-l3；位置、速度、电流环本身与插补细节见 u6-l3。
