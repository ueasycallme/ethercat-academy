单元诊断挑战

每单元一个真机场景、三个连续问题：逐题作答，答对才出现下一题，答错会给出推理和回看的课；三题全对记为该单元挑战完成。

U0 · 全景

从三条命令的输出判断：两台状态机各走到了哪一步，两条通路哪条能用。

场景：驱动器刚上电，主站 PC 上还没有运行任何应用程序。

$ ethercat master
Master0
  Phase: Idle
  …
$ ethercat slaves
0  0:0  PREOP  +  Servo
$ ethercat upload -p0 --type uint16 0x6041 0
0x0250 592

U1 · 物理层与帧

同一周期里的三条数据报，各自的 WKC 从不同角度指向同一个结论。

场景：线形连接 3 台从站。从站 1 有输出和输入，从站 2 只有输入，从站 3 只有输出，都在同一个域里。Wireshark 抓到同一周期的三条数据报（回帧）：

数据报地址回帧 WKC
BRDADO = 0x01302
FPRDADP = 0x0003，ADO = 0x01300
LRW域的逻辑地址4
$ ethercat domains
Domain0: LogBaseAddr 0x00000000, Size …, WorkingCounter 4/6

U2 · ESC 从站控制器

只用五个寄存器读数，说出状态、原因和看门狗时间。注意读数是小端字节序。

场景：主站程序停止之后，逐个读 ESC 寄存器：

$ ethercat reg_read -p0 0x0130 2
0x14 0x00
$ ethercat reg_read -p0 0x0134 2
0x1B 0x00
$ ethercat reg_read -p0 0x0440 2
0x00 0x00
$ ethercat reg_read -p0 0x0420 2
0x64 0x00
$ ethercat reg_read -p0 0x0400 2
0xC2 0x09

U3 · 协议与状态机

一次被拒绝的状态切换：谁拒绝的，差在哪几个字节，该让哪一边迁就。

场景：主站程序 activate 之后，从站停在 PREOP 且带 E。

$ ethercat slaves
0  0:0  PREOP  E  Servo
$ ethercat reg_read -p0 0x0134 2
0x1D 0x00
$ ethercat pdos -p0
SM2: PhysAddr …, DefaultSize 6, …
  RxPDO 0x1600 …
    PDO entry 0x6040:00, 16 bit
    PDO entry 0x607A:00, 32 bit

程序 syncs 里 0x1600 的映射：

{0x6040, 0x00, 16},
{0x607A, 0x00, 32},
{0x60B8, 0x00, 16},

U4 · 时间同步

间歇性的同步错误：先看配置里的余量，再看抖动。

场景：4 轴 DC 同步，主站周期 1 ms。几小时出现一次某一轴 SAFEOP + E，0x0134 = 0x1A 0x00。

/* 主站程序里的 DC 配置 */
ecrt_slave_config_dc(sc, 0x0300, 1000000, 0, 0, 0);

$ cyclictest …        # 实测最大延迟 380 µs
