电机控制链：三环、FOC 与插补

总线每周期送来的 607A 只是起点：驱动器里位置环、速度环、电流环一层套一层，越往里越快；主站给的点是否"每周期可达"，决定了跟随误差是平稳还是报错。

定位

本课目标

  1. 画出位置、速度、电流三环级联，以及电流环里的 FOC（Clarke、Park、反 Park、PWM）。
  2. 解释总线周期与各控制环周期的关系：为什么电流环比总线快一个数量级以上。
  3. 解释插补与跟随误差，读懂 6065、6066、60F4、606C。

    三环级联：谁给谁指令

    外环的输出是内环的指令：位置误差变成速度指令，速度误差变成电流（转矩）指令。内环必须比外环快得多，外环才能把内环当成"立刻跟上"的执行器。运行模式决定主站从哪一环切进来（u5-l2）。

    环输入输出典型周期主站从这里切入的模式
    位置环6062 位置指令（由 607A 得出）− 6064 实际位置速度指令1 ms（常与总线同）CSP（6060 = 8）
    速度环速度指令 − 实际速度电流指令 iq*250 µs 左右CSV（60FF，6060 = 9）
    电流环iq* − iq，id* − id电压指令 → PWM 占空比50–100 µs（10–20 kHz）CST（6071，6060 = 10）

    表中周期都是典型值，因驱动器而异；有的驱动器位置环也跑得比总线快，并在两个 607A 之间做细插补。

    FOC：电流环内部

    三相电流是正弦量，直接用 PI 跟踪效果差。FOC 用转子角 θ 把它们变到跟转子一起转的 d/q 坐标，在那里电流是直流量，PI 很好调：iq 管转矩，id 通常压到 0（表贴式永磁电机）。

    步骤输入输出作用
    Clarkeia、ib、iciα、iβ三相 → 两相静止坐标
    Parkiα、iβ、θid、iq静止 → 随转子旋转的坐标，正弦量变直流量
    PI 调节id* − id、iq* − iqvd、vq在直流量上闭环
    反 Parkvd、vq、θvα、vβ变回静止坐标
    SVPWMvα、vβ、母线电压三相占空比驱动逆变桥开关

    总线周期与控制周期

    总线每 1 ms 在 SYNC0 时刻交付一个新 607A，位置环在同一节拍用它；速度环在这 1 ms 里跑 4 次，电流环跑 16 次（按典型值）。所以总线只需要"准时"，不需要"很快"；电流环的快是驱动器本地的事。

    插补与跟随误差

    CSP 下驱动器只跟踪、不规划，所以主站每周期给的点必须是电机在一个周期里走得到的：相邻两点之差不能超过"最大速度 × 周期"。例如 20 位编码器（1 048 576 counts/圈）、3000 rpm、1 ms 周期，每周期最多约 52 429 counts（假设 6091/6092 为 1:1）。给得太远，跟随误差 60F4 = 6062 位置指令值 − 6064 位置实际值 瞬间变大，超过 6065 窗口并持续 6066 时间就报错。6062 是驱动器由 607A 经插补/轨迹生成得到的内部指令，未做细插补时 6062 与 607A 每周期相同。

    主从对照

    主站做什么

    • 规划整条轨迹（速度、加速度、加加速度受限）。
    • 插补：每个总线周期取轨迹上的下一个点写进 607A，相邻点之差受最大速度约束。
    • 使能前让 607A 等于 6064，避免使能瞬间跳变。
    • 监视 6041 bit13 与 60F4（可映射进 TxPDO），及时停机。

    驱动器做什么

    • SYNC0 时刻取新 607A，必要时在两个点之间细插补（因厂商而异）。
    • 位置环 → 速度环 → 电流环（FOC）→ PWM，逐层闭环。
    • 读编码器更新 6064、606C，算 60F4 = 6062 − 6064。
    • |60F4| 超过 6065 并持续 6066：置 6041 bit13，按厂商策略报故障或停车。

    在真机上看

    ethercat upload -p0 0x6065 0 --type uint32   # 跟随误差窗口
ethercat upload -p0 0x6066 0 --type uint16   # 超时 ms
ethercat upload -p0 0x606C 0 --type int32    # 实际速度
ethercat upload -p0 0x6062 0 --type int32    # 位置指令值
ethercat upload -p0 0x60F4 0 --type int32    # 跟随误差 = 6062 − 6064
ethercat upload -p0 0x6091 1 --type uint32   # 齿轮比 分子
ethercat upload -p0 0x6091 2 --type uint32   # 齿轮比 分母
ethercat upload -p0 0x6092 1 --type uint32   # 导程常数 进给
ethercat upload -p0 0x6092 2 --type uint32   # 导程常数 转数
    读数期望值说明
    0x6065非零，厂商默认值位置单位；0xFFFFFFFF 表示关闭监视，调试期不建议关
    0x6066几 ms 到几十 ms厂商默认值差异大
    0x606C（静止）约 0，有少量噪声单位因厂商而异
    0x606C（匀速）≈ 每周期增量 ÷ 周期如每 1 ms 增 1000 counts，速度约 1 000 000 counts/s（单位若为 counts/s）
    0x60F4（匀速）|6062 − 6064| 远小于 6065接近窗口说明增益不足或指令不可达
    0x6091 / 0x6092常为 1 / 1非 1:1 时 6065、607A 的单位不再是 counts

    自测

    误区与关联

    • 误区：CSP 下主站可以直接把终点写进 607A，驱动器会自己慢慢走过去。
      实际上：那是 PP 模式的行为。CSP 下驱动器把每个 607A 当作"这一拍就该到的位置"，主站必须自己插补。
    • 误区：总线周期越短，电机控制就越好。
      实际上：电流环、速度环在驱动器本地跑；总线周期主要影响轨迹分辨率和外环延迟，准时（抖动小）比快更重要。
    • 误区：跟随误差报警就调大 6065。
      实际上：先查指令是否可达、增益是否合适、机械是否卡滞；随意放大窗口会掩盖真实故障。
