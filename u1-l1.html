拓扑与端口：帧怎么走一圈

接成一条线的从站为什么实际上是一个环：ESC 按固定端口顺序转发，没接线的端口自动闭合，帧在去程被处理、在回程只被转发。

定位

本课目标

  1. 说出 ESC 端口 0–3 的帧处理顺序：0 → 处理单元 → 3 → 1 → 2 → 0。
  2. 解释为什么线形拓扑在物理上是一个环。
  3. 说出断线或末端无链路时，帧怎样被 ESC 自动闭环送回主站。

    机制拆解

    端口处理顺序是固定的

    ESC 内部只有一个处理单元，它挂在"端口 0 收到的帧"这条路上。帧处理完后按固定顺序依次交给下一个端口：端口打开就发出去，端口闭合就直接跳到再下一个。顺序只取决于芯片启用了哪些端口（ET1100 数据手册"帧处理顺序"一节）。

    启用的端口帧处理顺序
    0、10 → 处理单元 → 1 → 0
    0、1、20 → 处理单元 → 1 → 2 → 0
    0、1、30 → 处理单元 → 3 → 1 → 0
    0、1、2、30 → 处理单元 → 3 → 1 → 2 → 0

    所以主站方向的网线要接端口 0（常标 IN），下游接端口 1（常标 OUT）；端口 2、3 用来做分支。

    自动闭环：没链路的端口自己闭合

    每个端口的"回环"状态由 DL Control 寄存器 0x0101（即 0x0100 起的第 2 字节）里的两位控制，默认是 Auto。Auto 模式下，PHY 报告有链路就打开端口、把帧发出去；没有链路就闭合端口、帧在芯片内部直接转给顺序里的下一个端口。

    回环设置（每端口 2 位）行为
    00 Auto有链路打开，无链路闭合，全自动
    01 Auto close断链时自动闭合；链路恢复后不会仅因链路恢复而打开：主站再次写入该设置，或该端口收到有效以太网帧，都会使它重新打开
    10 Always open始终打开（无链路时帧会丢在这里）
    11 Always closed始终闭合

    线形拓扑为什么是环

    100BASE-TX 网线里有两对线，一对去、一对回（全双工）。帧沿去程线对穿过每台从站并被处理，到最后一台时端口 1 无链路自动闭合，同一帧转到回程线对，逐台只转发地回到主站。主站只需要一个网口，发出去的帧总会从同一个网口回来。

    主从对照

    主站做什么

    • 只用一个网口发帧，也在同一个网口收回同一帧，不需要知道网络怎么接也能通信。
    • 扫描时读每台从站的 DL Status（0x0110），根据哪些端口有链路推出拓扑：谁接在谁的哪个端口上。
    • 发出的帧如果没回来（超时），就知道环在某处断了，再逐台读 DL Status 找断点。
    • 冗余环（一句带过）：主站用第二个网口接到最后一台的端口 1；中间断线时两边各自闭环，两个网口分别收回一半，通信不中断。

    从站做什么

    • ESC 硬件完成全部转发，不需要从站 CPU 参与，也不需要固件运行。
    • 只有从端口 0 收进来的帧才经过处理单元被读写；从其他端口收进来的帧只转发。
    • 按每个端口的链路状态自动开合回环，并把链路、回环、通信状态写进 DL Status 给主站读。
    • 断线发生在哪里，哪里的两侧 ESC 就各自闭环，断点之前的从站照样能通信。

    误区与关联

    • 误区：最后一台从站收到帧后"应答"一个新帧给主站。
      实际上：没有应答帧。同一帧在末端被 ESC 硬件闭环，沿另一对线原路返回，主站收回的就是自己发出的那一帧（数据已被沿途改写）。
    • 误区：进线插 IN 还是 OUT 无所谓，反正都能通。
      实际上：处理单元只在端口 0 的接收路径上。插反后帧先被转发到下游、回来时才被这台处理，处理先后（位置编号）与接线顺序不一致，拓扑和 DC 延时测量都会乱。
    • 误区：DL Status 里某端口"物理链路 = 1"就说明通信正常。
      实际上：链路位只说明 PHY 检测到对端；还要看同一端口的"通信已建立"位和回环位。
