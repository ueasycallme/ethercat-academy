故障、急停与抱闸

驱动器出错时不等主站：自己按 605E 停车、抱闸、关功率级；主站要做的是读懂 603F，并用一个上升沿把它复位。

定位

本课目标

  1. 讲清故障反应路径：转换 13 → 14 → 15，以及 605E 决定怎么停。
  2. 解释 605A 快停选项码 0–8，区分停完回到禁止接通和停留在快速停止。
  3. 画出使能与停车时的抱闸时序，说明复位为什么是边沿而不是电平。

    机制拆解

    故障反应路径：13 → 14 → 15

    驱动器检测到故障后不等主站，自己走转换 13 进入故障反应（Fault reaction active），按 605E 停车；反应完成后自动走 14 进入故障（Fault），驱动功能关闭。离开故障只有一条路：主站在 6040 bit7 上产生上升沿（转换 15），而且故障原因必须已经消失，否则驱动器会立刻再次进入故障反应。

    605E 取值故障反应（Fault reaction option code）
    0关闭驱动功能，电机自由停转
    1按减速斜坡（slow down ramp）停车
    2按快停斜坡（quick stop ramp，减速度见 6085）停车
    3按电流极限停车
    4按电压极限停车
    负值厂商定义

    功率级自身的故障（例如过流、短路）往往已无法按斜坡减速，驱动器会直接关断；哪些故障遵循 605E、默认值是多少，因厂商而异。

    Quick stop：605A 决定怎么停、停完去哪

    6040 bit2 清零即 Quick stop 命令（低有效），在运行使能下触发转换 11。605A 的 1–4 与 5–8 停车方式一一对应，区别只在停完后：1–4 自动回禁止接通并关断功率级，5–8 停留在快速停止继续出力保持位置。

    605A停车方式停完后
    0关闭驱动功能，自由停转禁止接通
    1减速斜坡禁止接通（转换 12）
    2快停斜坡（6085）禁止接通（转换 12）
    3电流极限禁止接通（转换 12）
    4电压极限禁止接通（转换 12）
    5减速斜坡停留在快速停止
    6快停斜坡（6085）停留在快速停止
    7电流极限停留在快速停止
    8电压极限停留在快速停止

    同类的还有 605B Shutdown 选项码（转换 8）和 605C Disable operation 选项码（转换 5），取值 0 = 直接关闭驱动功能、1 = 按减速斜坡停车后关闭；605D Halt 选项码 1–4 与 605A 的 1–4 停车方式相同，但停完仍留在运行使能。减速斜坡通常取 6084 Profile deceleration，具体因模式与厂商而异。

    抱闸时序

    弹簧式抱闸断电抱住、通电松开，机械动作需要几十到上百毫秒。使能时驱动器先让电机出力，再松闸，等抱闸真正松开才开始运动；停车时先把速度降到 0，再抱闸，等抱闸真正压紧后才关功率级。两段等待时间由驱动器参数设定，对象号与默认值因厂商而异。

    603F 错误码与复位

    603F Error code 是 16 位，编码沿用 CiA 301 紧急报文：第一位十六进制数是大类（2 电流、3 电压、4 温度、5 设备硬件、6 设备软件、7 附加模块、8 监控、9 外部错误、F 附加功能），0xFF00–0xFFFF 留给厂商。1001 Error register 是 8 位快速分类：bit0 通用、bit1 电流、bit2 电压、bit3 温度、bit4 通信、bit5 设备行规、bit7 厂商。

    603F含义大类
    0x0000无错误—
    0x2310持续过流（Continuous over current）电流
    0x3210直流母线过压（DC link over-voltage）电压
    0x3220直流母线欠压（DC link under-voltage）电压
    0x4310驱动器过温（Excess temperature drive）温度
    0x8611跟随误差（Following error）监控
    0xFF00–0xFFFF厂商自定义，查驱动器手册厂商

    复位只认 bit7 的 0 → 1 边沿：一直写 0x0080 只会复位一次；若第一次复位时原因仍在，之后必须先写回 bit7 = 0 再置 1 才会再试。复位后驱动器在禁止接通，主站要重新走 0x0006 → 0x0007 → 0x000F。

    主从对照

    主站做什么

    • PREOP 阶段用 SDO 设好 605A、605E、6085 等停车参数。
    • 每周期检查 6041 bit3，一旦故障就读 603F 并记录；CoE 紧急报文会主动推送同一错误码，IgH 可用 ecrt_slave_config_emerg_pop() 取（以所用版本的 ecrt.h 为准）。
    • 复位：先排除原因，保持 bit7 = 0 至少一个周期再置 1；复位后重走 0x0006 → 0x0007 → 0x000F，并让 607A 对齐 6064。
    • 需要受控停车时发 Quick stop（0x0002），不要直接发 Disable voltage（0x0000），后者在运行使能下会立即关断、自由停转。

    从站做什么

    • 持续监测过流、过压、欠压、过温、跟随误差等，出错立即走转换 13，不等主站。
    • 按 605E 或 605A 执行停车，并在内部完成抱闸与关功率级的先后顺序。
    • 写 603F、1001，并通过 CoE Emergency 报文上报。
    • 只在 bit7 上升沿且故障原因已消失时走转换 15 回到禁止接通。

    在真机上看

    驱动器报故障时，按"状态 → 错误码 → 分类 → 停车配置"的顺序读：

    ethercat upload -p0 0x6041 0 --type uint16   # 是否在故障：& 0x004F == 0x0008
ethercat upload -p0 0x603F 0 --type uint16   # 错误码
ethercat upload -p0 0x1001 0 --type uint8    # 错误寄存器（CiA 301）
ethercat upload -p0 0x605A 0 --type int16    # 快停选项码
ethercat upload -p0 0x605E 0 --type int16    # 故障反应选项码
ethercat upload -p0 0x6085 0 --type uint32   # 快停减速度
ethercat upload -p0 0x60FD 0 --type uint32   # 数字输入（限位、原点、厂商位）
ethercat upload -p0 0x60FE 1 --type uint32   # 数字输出（标准 bit0 为 set brake，是否实现因厂商而异）
    读数期望值（示例）说明
    60410x0218掩码 0x004F 后为 0x0008，故障
    603F0x4310驱动器过温；0xFF00 以上查厂商手册
    10010x09bit0 通用 + bit3 温度；故障清除后回 0
    605A / 605E常见 2快停斜坡停车；默认值因厂商而异
    60FDbit0 / bit1 / bit2负限位 / 正限位 / 原点开关；bit3 为 interlock，bit16–31 厂商定义
    抱闸状态因厂商而异60FD 的标准位里没有抱闸位；有抱闸反馈的驱动器一般放在 60FD bit16–31 或厂商对象，位号查手册

    自测

    误区与关联

    • 误区：故障复位是电平，一直写 0x0080 就行。
      实际上：只认 bit7 的 0 → 1 边沿；每次重试都要先写回 0。
    • 误区：605A 或 605E = 0 也会减速停车。
      实际上：0 表示直接关闭驱动功能，电机自由停转；垂直轴只剩抱闸兜底。
    • 误区：6040 的 Quick stop 就是急停安全功能。
      实际上：Quick stop 是经过总线的普通命令，依赖通信和状态机；安全转矩关断（STO）等安全功能走硬接线或安全通信，不经过 CiA402 状态机，本课不展开。

    关联：状态与转换编号见 u5-l1；跟随误差 6065 与三环见 u6-l3；把 603F 放进整体诊断流程见 u7-l2。故障发生时驱动器还会通过 CoE Emergency 报文主动上报同一错误码（与 603F 同一编码），报文格式见 u3-l2。
