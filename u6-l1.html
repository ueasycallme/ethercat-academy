主站程序：IgH 架构与周期任务

一个 IgH 主站程序分两段：先把"要什么从站、要哪些 PDO、放在哪里"一次配好并激活，然后每个周期固定地收、处理、读、算、写、排队、发。

定位

本课目标

  1. 画出 IgH 架构：应用、libethercat 用户库、ec_master 内核模块、网卡驱动各在哪一层。
  2. 按顺序写出程序生命周期：request_master 到 activate 的配置阶段，以及 activate 之后的运行阶段。
  3. 说出周期任务六步，以及 DC 同步调用和 WKC 检查放在哪里。

前置课

    主动画

    机制拆解

    IgH 的四层

    应用程序只和 libethercat 打交道；libethercat 把每个 ecrt_* 调用变成对字符设备 /dev/EtherCAT0 的 ioctl。真正的主站状态机、域、从站配置都在内核模块 ec_master 里，它通过专用网卡驱动直接收发以太网帧，不经过 TCP/IP 协议栈。

    两个阶段：配置期与运行期

    从 ecrt_request_master 到 ecrt_master_activate 之前只是在内核里登记"期望的配置"，并不立即访问从站。activate 之后主站状态机在后台把从站配到 OP，此后不能再改 PDO、域、DC 等配置。要改配置，只能 ecrt_master_deactivate 或释放主站后重来。

    阶段调用作用
    配置期ecrt_request_master(0)独占 0 号主站，返回 ec_master_t *
    ecrt_master_create_domain建一个域：一块过程映像，对应周期帧里的一段逻辑地址
    ecrt_master_slave_config(master, alias, position, vendor_id, product_code)声明"这个位置上应该是这个型号"，不符则不配置它
    ecrt_slave_config_pdos(sc, EC_END, syncs)声明 SM 与 PDO 的分配和映射，激活后由主站通过 SDO 写到从站
    ecrt_domain_reg_pdo_entry_list(domain, regs)把 PDO 条目登记进域，并返回每项在域里的字节偏移
    ecrt_slave_config_dc(sc, assign_activate, sync0_cycle, sync0_shift, sync1_cycle, sync1_shift)启用该从站的 SYNC0/SYNC1；assign_activate 取 ESI 中的 AssignActivate
    切换ecrt_master_activate冻结配置，计算域布局，主站开始把从站推进到 OP
    ecrt_domain_data取域内存指针 pd，之后用 EC_READ_*/EC_WRITE_*(pd + 偏移) 访问
    运行期周期任务（见下节）只读写过程数据，不再改配置

    周期六步与 DC 调用位置

    每个周期先收回上一周期发出的帧，再解析，然后应用读输入、算、写输出，再把新数据排队、发出。DC 相关的三个调用放在 queue 之后、send 之前，这样它们的数据报会和过程数据挤在同一次发送里。

    ecrt_domain_state(domain, &ds) 在 process 之后调用，给出 ds.working_counter（本周期实际 WKC）和 ds.wc_state：EC_WC_ZERO 没有从站交换数据，EC_WC_INCOMPLETE 部分交换，EC_WC_COMPLETE 全部交换。只有 EC_WC_COMPLETE 时读到的输入才可信。

    实时前提：PREEMPT_RT、SCHED_FIFO、mlockall

    周期任务要准时，靠的不是 IgH 本身，而是操作系统能否在截止时刻前把线程叫醒并让它跑完。下面三项分别去掉三类抖动来源；还剩多少抖动因硬件而异，要在自己的机器上用 cyclictest 测（见 u4-l2）。

    机制解决什么抖动来源在最小示例里对应哪里
    PREEMPT_RT 内核普通内核里有些内核路径和中断处理不可抢占，实时线程醒来后要等它们结束；RT 补丁让内核大部分路径可抢占、中断处理线程化，降低最坏情况延迟系统配置：安装并启动 PREEMPT_RT 内核（uname -v 通常显示 PREEMPT_RT 或 PREEMPT RT 字样，因内核版本而异）；代码里不体现
    SCHED_FIFO 实时优先级普通调度（SCHED_OTHER）下周期线程要和其他进程分时间片；实时优先级让它一就绪就抢占普通任务sched_setscheduler(0, SCHED_FIFO, &sp)，优先级 80，放在 activate 之后、进入循环之前
    mlockall运行中首次访问的内存页触发缺页，甚至换页到磁盘，一次就可能拖过一个周期mlockall(MCL_CURRENT | MCL_FUTURE)，main() 开头第一步
    CPU 隔离（可选）其他任务和中断与周期线程抢同一个 CPU 核系统配置：内核参数 isolcpus 预留一个核，再把周期线程绑到该核；最小示例未做

    主从对照

    主站程序做什么

    • 配置期：只登记期望的从站、PDO 映射、域条目和 DC 参数，不直接碰从站。
    • activate 后：内核主站状态机经 SDO 写 1C12/1C13 与映射，配 SM、FMMU、DC，再请求 SAFEOP、OP。
    • 运行期：每周期 receive → process → 读算写 → queue → DC 同步 → send，检查 wc_state。
    • CSP 下使能前把目标位置设成实际位置，使能后每周期只给可达的增量。

    从站看到什么

    • 主站空闲（Idle）阶段：被扫描、读 SII，被带到 PREOP。
    • activate 后：收到 SDO 写映射、SM/FMMU/DC 寄存器写入，AL Control 依次请求 SAFEOP、OP。
    • 运行期：每周期一帧 LRW 经过，从输出 SM 取 6040/607A，往输入 SM 填 6041/6064，WKC 加 3。
    • 主站程序停止发帧：输出 SM 看门狗到期，退回 SAFEOP 并报 0x001B。

    在真机上看

    下面是单从站 CSP 的最小主站程序。VENDOR_ID、PRODUCT_CODE 是占位值，必须换成 ethercat slaves -v 读出的 Vendor Id 与 Product code；1600/1A00 的映射内容要该驱动器支持（有的驱动器固定映射，按其 ESI 调整）。

    ethercat slaves -v        # 抄下 Vendor Id、Product code；看 DC 是否支持
ethercat pdos -p0         # 核对驱动器默认的 1600/1A00 映射
    /* min_csp.c —— 单从站 CSP 最小主站（IgH EtherCAT Master 1.5.x / 1.6 用户态 API）
 * 编译：gcc -O2 -Wall min_csp.c -o min_csp -I/opt/etherlab/include -L/opt/etherlab/lib -lethercat
 *       （头文件与库路径取决于安装前缀）
 * 运行：sudo ./min_csp          Ctrl+C 退出
 */
#include <stdio.h>
#include <stdint.h>
#include <signal.h>
#include <time.h>
#include <sched.h>
#include <sys/mman.h>
#include <ecrt.h>

/* 占位值：从 `ethercat slaves -v` 读取后替换 */
#define VENDOR_ID     0x00000000
#define PRODUCT_CODE  0x00000000
#define SLAVE_POS     0, 0                 /* alias, position */
#define PERIOD_NS     1000000L             /* 1 ms */
#define NSEC_PER_SEC  1000000000L

static volatile sig_atomic_t run = 1;
static void on_sig(int s) { (void)s; run = 0; }

/* 1600（RxPDO，主站→从站）与 1A00（TxPDO，从站→主站）的映射 */
static ec_pdo_entry_info_t rx_entries[] = {
    {0x6040, 0x00, 16},                    /* 控制字 */
    {0x607A, 0x00, 32},                    /* 目标位置 */
};
static ec_pdo_entry_info_t tx_entries[] = {
    {0x6041, 0x00, 16},                    /* 状态字 */
    {0x6064, 0x00, 32},                    /* 实际位置 */
};
static ec_pdo_info_t rx_pdos[] = { {0x1600, 2, rx_entries} };
static ec_pdo_info_t tx_pdos[] = { {0x1A00, 2, tx_entries} };
static ec_sync_info_t syncs[] = {
    {0, EC_DIR_OUTPUT, 0, NULL,    EC_WD_DISABLE},   /* SM0 邮箱出 */
    {1, EC_DIR_INPUT,  0, NULL,    EC_WD_DISABLE},   /* SM1 邮箱入 */
    {2, EC_DIR_OUTPUT, 1, rx_pdos, EC_WD_ENABLE},    /* SM2 输出，开看门狗 */
    {3, EC_DIR_INPUT,  1, tx_pdos, EC_WD_DISABLE},   /* SM3 输入 */
    {0xff}
};

/* 域内字节偏移，由 ecrt_domain_reg_pdo_entry_list 填写 */
static unsigned int off_ctrl, off_tgt, off_stat, off_pos;
static const ec_pdo_entry_reg_t regs[] = {
    {SLAVE_POS, VENDOR_ID, PRODUCT_CODE, 0x6040, 0, &off_ctrl},
    {SLAVE_POS, VENDOR_ID, PRODUCT_CODE, 0x607A, 0, &off_tgt},
    {SLAVE_POS, VENDOR_ID, PRODUCT_CODE, 0x6041, 0, &off_stat},
    {SLAVE_POS, VENDOR_ID, PRODUCT_CODE, 0x6064, 0, &off_pos},
    {}
};

/* CiA402：按状态字决定下一拍的控制字（掩码见 u5-l1） */
static uint16_t cia402_next(uint16_t sw, uint16_t last_cw)
{
    if ((sw & 0x004F) == 0x0008)                        /* Fault */
        return (last_cw & 0x0080) ? 0x0000 : 0x0080;    /* 0 与 0x80 交替，制造上升沿复位 */
    if ((sw & 0x004F) == 0x0040) return 0x0006;         /* Switch On Disabled → Shutdown */
    if ((sw & 0x006F) == 0x0021) return 0x0007;         /* Ready to Switch On → Switch On */
    if ((sw & 0x006F) == 0x0023) return 0x000F;         /* Switched On → Enable Operation */
    if ((sw & 0x006F) == 0x0027) return 0x000F;         /* Operation Enabled：保持 */
    return 0x0000;                                      /* 其他状态：回到 Switch On Disabled 重走 */
}

static uint64_t ts_ns(const struct timespec *t)
{
    return (uint64_t)t->tv_sec * NSEC_PER_SEC + (uint64_t)t->tv_nsec;
}

int main(void)
{
    struct sched_param sp = { .sched_priority = 80 };
    struct timespec wake;
    ec_domain_state_t ds;
    uint8_t *pd;
    uint16_t cw = 0;
    int32_t target = 0;
    uint32_t n = 0;

    /* 锁定内存，避免运行中缺页 */
    if (mlockall(MCL_CURRENT | MCL_FUTURE) == -1) { perror("mlockall"); return 1; }
    signal(SIGINT, on_sig);
    signal(SIGTERM, on_sig);

    /* ---------- 配置期 ---------- */
    ec_master_t *master = ecrt_request_master(0);
    if (!master) return 1;
    ec_domain_t *domain = ecrt_master_create_domain(master);
    if (!domain) return 1;
    ec_slave_config_t *sc = ecrt_master_slave_config(master, SLAVE_POS, VENDOR_ID, PRODUCT_CODE);
    if (!sc) return 1;
    if (ecrt_slave_config_pdos(sc, EC_END, syncs)) return 1;
    if (ecrt_slave_config_sdo8(sc, 0x6060, 0, 8)) return 1;      /* PREOP 时写 6060 = 8（CSP） */
    if (ecrt_domain_reg_pdo_entry_list(domain, regs)) return 1;
    /* 0x0300：启用 SYNC0 的常见 AssignActivate 值，以该从站 ESI 的 <AssignActivate> 为准 */
    ecrt_slave_config_dc(sc, 0x0300, PERIOD_NS, 0, 0, 0);

    clock_gettime(CLOCK_MONOTONIC, &wake);
    ecrt_master_application_time(master, ts_ns(&wake));        /* 激活前先给一次应用时间 */
    if (ecrt_master_activate(master)) return 1;                  /* 此后不能再改配置 */
    if (!(pd = ecrt_domain_data(domain))) return 1;

    /* 实时调度：SCHED_FIFO，优先级按系统规划 */
    if (sched_setscheduler(0, SCHED_FIFO, &sp) == -1) perror("sched_setscheduler");

    /* ---------- 运行期 ---------- */
    while (run) {
        wake.tv_nsec += PERIOD_NS;
        while (wake.tv_nsec >= NSEC_PER_SEC) { wake.tv_nsec -= NSEC_PER_SEC; wake.tv_sec++; }
        clock_nanosleep(CLOCK_MONOTONIC, TIMER_ABSTIME, &wake, NULL);

        ecrt_master_receive(master);                 /* ① 收 */
        ecrt_domain_process(domain);                 /* ② 解析，更新 WKC */
        ecrt_domain_state(domain, &ds);
        if (ds.wc_state != EC_WC_COMPLETE && n % 1000 == 0)   /* 演示用；正式程序别在实时循环里 printf */
            fprintf(stderr, "WKC %u, wc_state %d\n", ds.working_counter, ds.wc_state);

        uint16_t sw  = EC_READ_U16(pd + off_stat);   /* ③ 读 */
        int32_t  act = EC_READ_S32(pd + off_pos);

        if ((sw & 0x006F) != 0x0027)                  /*    算：未使能时目标跟随实际，避免使能瞬间跳变 */
            target = act;
        /* else target += 每周期可达的增量;  在此接入你的插补器 */
        cw = cia402_next(sw, cw);

        EC_WRITE_U16(pd + off_ctrl, cw);             /*    写 */
        EC_WRITE_S32(pd + off_tgt, target);

        ecrt_domain_queue(domain);                   /* ④ 排队 */
        ecrt_master_application_time(master, ts_ns(&wake));   /* ⑤ DC：应用时间 */
        ecrt_master_sync_reference_clock(master);    /*    参考时钟对齐到应用时间 */
        ecrt_master_sync_slave_clocks(master);       /*    其他从站对齐到参考时钟 */
        ecrt_master_send(master);                    /* ⑥ 发 */
        n++;
    }

    ecrt_release_master(master);
    return 0;
}
    sudo ./min_csp &
ethercat master           # Phase 应为 Operation
ethercat slaves           # 位置 0 应为 OP
ethercat domains          # WorkingCounter 实际/期望
    读数期望值说明
    ethercat masterPhase: Operation应用已 activate；未运行程序时是 Idle
    ethercat slaves0 0:0 OP +"+" 表示配置成功；E 表示有错误
    ethercat domainsSize 12，WorkingCounter 3/32+4+2+4 字节；一台从站读写都命中，LRW 的 WKC 为 3
    6041（EC_READ）低 7 位 0x27 模式即 (sw & 0x6F) == 0x27，Operation Enabled
    wc_stateEC_WC_COMPLETE拔网线或从站掉 SAFEOP 时变 INCOMPLETE 或 ZERO

    程序退出后不再发周期帧，从站的输出 SM 看门狗到期、退回 SAFEOP 并报 0x001B。这是正常现象，不是程序 bug。

    自测

    误区与关联

    • 误区：调用 ecrt_master_slave_config 时主站就去配置从站了。
      实际上：配置期只在内核里登记期望配置，真正的 SDO 下载、SM/FMMU 写入在 activate 之后由主站状态机在后台完成。
    • 误区：从站进了 OP 就说明周期数据没问题。
      实际上：要每周期看 ecrt_domain_state 的 wc_state；WKC 不完整时读到的输入可能是旧值。
    • 误区：用相对睡眠 usleep(1000) 做周期。
      实际上：相对睡眠会累积误差；要用 clock_nanosleep（CLOCK_MONOTONIC + TIMER_ABSTIME）按绝对时刻唤醒，并配合 mlockall 与 SCHED_FIFO。

    关联：PDO 与域偏移见 u3-l3；DC 与 SYNC0 见 u4-l1、u4-l2；控制字状态机见 u5-l1；程序停止后从站为何停在 SAFEOP，见 u7-l2 的案例。
