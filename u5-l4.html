限制、回零与探针：让轴在真实机械上安全可用

驱动器出厂时既不知道你的机械用什么单位，也不知道边界在哪；增量编码器上电后连自己在哪都不知道。本课用四组对象补上这三件事：因子组、限制对象、回零对象和探针对象。

定位

本课目标

  1. 用因子组 608F、6091、6092（及 6096、6097）把用户单位换算成编码器增量，知道 607E 极性位。
  2. 说出位置、速度、转矩三层限制对象和窗口类对象各在哪一环生效、超限会怎样。
  3. 执行一次回零：6060 = 6、6098 选方法、6040 bit4 启动，看 6041 bit12/bit13 判断结果。
  4. 用 60B8/60B9 配置并读取探针，知道锁存值在 60BA–60BD。

    机制拆解

    因子组：用户单位怎样变成编码器增量

    主站写的 607A、读的 6064、设的 607D 都是用户单位，驱动器内部用编码器增量，二者靠因子组换算：增量 = 用户位置 × (608F:01 ÷ 608F:02) × (6091:01 ÷ 6091:02) ÷ (6092:01 ÷ 6092:02)。6096 速度因子、6097 加速度因子对速度、加速度做同样的事（有的驱动器直接由位置因子推导，因厂商而异）。607E 极性位 bit7 反转位置方向、bit6 反转速度方向，用于电机装反时不改接线。

    对象本例取值含义
    608F:01 / :021048576 / 120 位编码器：电机每转 220 个增量
    6091:01 / :0210 / 1齿轮比：电机转 10 圈，输出轴转 1 圈
    6092:01 / :02360000 / 1进给常数：输出轴 1 圈 = 360 000 个用户单位，即用户单位 0.001°
    结果1048576 × 10 ÷ 360000 ≈ 29.131 个用户单位 ≈ 29.13 个增量；小数部分如何取整、是否累积误差因厂商而异

    限制分层：夹在哪一环、什么单位、超限怎样

    限制对象按它夹住的信号分层：位置限幅在位置环入口，速度限幅在速度环入口，转矩限幅在电流环入口，窗口类对象不夹信号，只判断"到没到、差多少"。所以位置限幅只管位置类模式，CST 下能约束电机的只剩转矩层。

    层对象单位作用位置超限时
    位置607D:01/:02 软件限位用户位置单位位置指令进位置环前（PP、CSP、IP 等位置类模式）目标被裁剪到限位或被拒绝，是否报警因厂商而异；多数驱动器回零后才生效
    位置607B:01/:02 位置范围限制用户位置单位位置值的数值范围（旋转轴取模）超出后数值回绕到另一端，不是停车限位
    速度607F 最大轮廓速度用户速度单位轮廓速度与速度指令被限幅
    速度6080 电机最大转速以驱动器手册为准（多为 rpm）速度环入口被限幅；超速是否报故障因厂商而异
    转矩6072 最大转矩额定转矩的 ‰电流环入口被限幅，6041 bit11 = 1
    转矩6073 最大电流额定电流的 ‰电流环被限幅
    转矩60E0 / 60E1 正 / 负转矩限制额定转矩的 ‰电流环入口，分方向被限幅，6041 bit11 = 1
    窗口6065 / 6066用户位置单位 / ms跟随误差 60F4 = 6062 − 6064超窗口且超时：bit13 Following error，常伴随故障
    窗口6067 / 6068用户位置单位 / ms位置到达判断进窗口并保持够时间：bit10 Target reached
    窗口606D / 606E用户速度单位 / ms速度到达判断（PV）进窗口并保持够时间：bit10 Target reached

    回零方法：6098 选一种参考信号

    回零就是用一个可重复的物理信号（限位开关、原点开关、编码器零脉冲）给增量坐标定锚，完成后驱动器把零点处的 6064 设为 607C。1–14 用"开关 + 零脉冲"，17–30 是同样的开关逻辑但零点取开关边沿，33/34 只找零脉冲，35（新版标准改号为 37）不运动。6040 bit4 上升沿启动，bit8 Halt 中止；6041 bit12 = 1 且 bit13 = 0 表示成功，bit13 = 1 表示出错。

    方法参考信号零点在哪适用
    1 / 2负 / 正限位开关 + 零脉冲离开限位开关后遇到的第一个零脉冲没有原点开关、要求高重复精度
    17 / 18负 / 正限位开关限位开关的释放沿没有零脉冲的编码器
    19–22原点开关（19/20 开关在正侧有效，21/22 在负侧有效）原点开关边沿，19/21 与 20/22 从边沿的不同侧逼近有独立原点开关的轴
    33 / 34只用零脉冲向负 / 正方向遇到的第一个零脉冲单圈内定位、行程极短
    35 / 37无当前位置绝对编码器一次性设零、调试
    其余3–14、23–30 为原点开关与零脉冲、限位的组合；各驱动器支持哪些方法、两档速度怎样用，以驱动器手册为准

    探针：让硬件在边沿那一刻记下位置

    探针（touch probe）在驱动器硬件里锁存位置，精度与总线周期无关，适合测量工件边缘、飞剪对标或回零后复核。60B8 = 0x0011 表示使能探针 1、单次模式、数字输入触发、正沿锁存；锁存后 60B9 bit1 置 1，位置在 60BA。单次模式锁存一次后不再更新，再次布防一般要把对应边沿使能位清零再置 1，以驱动器手册为准。

    位60B8 功能字60B9 状态字
    0使能探针 1探针 1 已使能
    10 = 单次（只锁第一次）/ 1 = 连续探针 1 正沿已锁存（60BA 有效）
    2触发源：0 = 探针 1 数字输入，1 = 编码器零脉冲探针 1 负沿已锁存（60BB 有效）
    3触发源扩展（与 bit2 组成 2 位，10 = 由 60D0 选择），以驱动器手册为准保留
    4探针 1 正沿锁存使能保留
    5探针 1 负沿锁存使能保留
    6–7保留 / 厂商定义厂商定义（有的驱动器用作连续模式的翻转位）
    8–13探针 2，含义同 bit0–5bit8–10 探针 2，含义同 bit0–2；其余保留
    14–15保留厂商定义

    锁存值：60BA 探针 1 正沿位置、60BB 探针 1 负沿位置、60BC 探针 2 正沿位置、60BD 探针 2 负沿位置，单位都是用户位置单位。

    主从对照

    主站做什么

    • PREOP 用 SDO 写因子组 608F、6091、6092（及 6096、6097、607E），再写限制 607D、607F、6072、60E0/60E1 和窗口 6065–6068。
    • 回零：写 6060 = 6 并等 6061 = 6；写 6098、6099、609A、607C；在运行使能下让 6040 bit4 从 0 变 1；监视 6041 bit12、bit13，必要时用 bit8 Halt 中止。
    • 回零完成后 6064 会突变为 607C：切回 CSP 前先把 607A 对齐新的 6064。
    • 探针：写 60B8，每周期读 60B9，看到对应位为 1 再取 60BA/60BB。

    从站做什么

    • 用因子组把用户单位换算成编码器增量，所有位置、速度、加速度对象都按用户单位解释。
    • 位置指令先过 607D，速度过 607F/6080，转矩过 6072/60E0/60E1；被夹住时置 6041 bit11。
    • 按 6098 执行回零程序：读 60FD 的限位、原点位和编码器零脉冲，完成后把零点处的 6064 设为 607C 并置 bit12。
    • 探针输入出现所选边沿时由硬件锁存位置到 60BA–60BD，并置 60B9 对应位。

    在真机上看

    先把参数读出来核对（主站程序不运行时用 SDO）：

    ethercat upload -p0 0x608F 1 --type uint32   # 编码器增量
ethercat upload -p0 0x608F 2 --type uint32   # 电机转数
ethercat upload -p0 0x6091 1 --type uint32   # 齿轮比：电机转
ethercat upload -p0 0x6091 2 --type uint32   # 齿轮比：轴转
ethercat upload -p0 0x6092 1 --type uint32   # 进给常数
ethercat upload -p0 0x607D 1 --type int32    # 软件限位最小
ethercat upload -p0 0x607D 2 --type int32    # 软件限位最大
ethercat upload -p0 0x607F 0 --type uint32   # 最大轮廓速度
ethercat upload -p0 0x6072 0 --type uint16   # 最大转矩 ‰
ethercat upload -p0 0x60E0 0 --type uint16   # 正转矩限制 ‰
ethercat upload -p0 0x60E1 0 --type uint16   # 负转矩限制 ‰
ethercat upload -p0 0x6098 0 --type int8     # 回零方法
ethercat upload -p0 0x607C 0 --type int32    # 原点偏移
ethercat upload -p0 0x60B8 0 --type uint16   # 探针功能字

    如果驱动器允许用 SDO 写 6040（是否允许、要求哪个 ESM 状态因厂商而异；主站程序在跑时 PDO 会覆盖 SDO），可以手动回零一次。确认轴附近安全、限位开关接好再做：

    ethercat download -p0 0x6060 0 6 --type int8        # 回零模式
ethercat upload   -p0 0x6061 0 --type int8          # 应读回 6
ethercat download -p0 0x6040 0 0x0006 --type uint16
ethercat download -p0 0x6040 0 0x0007 --type uint16
ethercat download -p0 0x6040 0 0x000F --type uint16 # 运行使能
ethercat download -p0 0x6040 0 0x001F --type uint16 # bit4 上升沿，开始回零
ethercat upload   -p0 0x6041 0 --type uint16        # 看 bit12 / bit13 / bit10
ethercat upload   -p0 0x6064 0 --type int32         # 完成后应等于 607C
    读数期望值（示例，因厂商而异）说明
    608F:01 / :021048576 / 1取决于编码器位数
    6091 / 609210:1 / 360000:1本课算例；出厂默认常为 1:1，需要按机械填写
    607D:01 / :02−80000 / 80000两者都为 0 时是否表示关闭软件限位，因厂商而异
    6072、60E0、60E1如 3000（300 %）额定转矩的 ‰；默认值因厂商而异
    609817 或 35支持哪些方法查驱动器手册；不支持的值写入时常返回 SDO abort
    60B80x0000未使能；写 0x0011 后才锁存
    6041（回零完成）0x1637bit12 = 1、bit13 = 0、bit10 = 1；bit13 = 1 表示回零出错
    6064（回零完成）等于 607C停在零点时；607C 的符号约定以驱动器手册为准

    自测

    误区与关联

    • 误区：改了 607D 就能防撞。
      实际上：速度过快时减速距离不够仍会冲过去；而且位置限幅只对位置类模式生效，转矩模式只能靠 60E0/60E1 和硬限位。
    • 误区：绝对编码器不用回零。
      实际上：绝对编码器知道自己在哪，但不知道机械零点在哪，仍需一次设零（写 607C 或用方法 35/37），之后断电才不丢。
    • 误区：60B8 写 1 就能用探针。
      实际上：0x0001 只使能、没有选任何边沿；还要置 bit4/bit5 选边沿、确认触发源，主站要读 60B9 判断已锁存再取 60BA。

    关联：模式切换与 6061 见 u5-l2；Halt 与停车方式见 u5-l3；限幅所在的三环见 u6-l3。回零完成后 6064 突变为 607C，切回 CSP 前没把 607A 对齐，就是 u7-l2 案例 7「使能瞬间电机猛冲」。
